# Контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке»

## Краткое описание проекта
Информационный сайт «Спасатели Москвы» представляет собой каталог структур и направлений деятельности московского пожарно-спасательного гарнизона (ДГОЧСиПБ и ГУ МЧС России). Сайт позволяет пользователям ознакомиться с историей службы, узнать о требованиях к кандидатам, посмотреть характеристики подразделений и отправить обращение через форму обратной связи.

## Используемый CSS-фреймворк
Bootstrap 5.3.8.

## Способ подключения Bootstrap
Bootstrap подключён **локально** (без использования CDN). Файлы фреймворка размещены в папке `vendor/bootstrap/`.
Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключён после Bootstrap для переопределения стилей и настройки фирменной цветовой схемы МЧС.

## Структура проекта
- `index.html` — Главная страница (анимированная статистика, направления);
- `catalog.html` — Каталог направлений (карточки, значки, JS-фильтры);
- `product.html` — Страница ГУ МЧС (характеристики, таблица, вкладки, аккордеон);
- `psc.html`, `mac.html`, `mgpss.html` — Уникальные страницы городских структур с галереями;
- `order.html` — Форма обратной связи (с JS-валидацией);
- `contacts.html` — Контакты с интерактивной картой;
- `history.html` — История службы;
- `css/custom.css` — Пользовательские стили;
- `images/` — Изображения и эмблемы;
- `vendor/bootstrap/` — Локальные файлы фреймворка;
- `README.md` — Описание проекта.

## Самостоятельные доработки и уникальные фишки (JavaScript)
Помимо базовых требований, в проект были добавлены следующие интерактивные элементы:
1. **Интерактивная карта** на странице «Контакты» (встроен виджет Яндекс.Карт с адаптивным контейнером `ratio`).
2. **Анимированные счетчики (Animated Counters)** на главной странице. При прокрутке цифры плавно увеличиваются от 0 до заданного значения с использованием `IntersectionObserver`.
3. **Кнопка «Наверх» (Back to top)**. Плавная прокрутка страницы вверх. Кнопка появляется при прокрутке страницы вниз и присутствует на всех страницах сайта.
4. **Индикатор прогресса прокрутки (Scroll Progress Bar)**. Тонкая линия в самом верху экрана, которая заполняется по мере чтения страницы, показывая процент прокрученного контента.
5. **Анимация появления контента (Scroll Reveal)**. Блоки и карточки на страницах плавно выезжают снизу и проявляются при попадании в область видимости пользователя.
6. **Фильтрация каталога**. На странице `catalog.html` реализована сортировка карточек по категориям (городские/федеральные) с помощью JavaScript.
7. **Валидация формы**. На странице `order.html` добавлена проверка обязательных полей и вывод сообщения об успешной отправке.
