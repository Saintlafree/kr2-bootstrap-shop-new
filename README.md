# Контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке»

## Краткое описание проекта
Информационный сайт «Спасатели Москвы» представляет собой каталог структур и направлений деятельности московского пожарно-спасательного гарнизона (ДГОЧСиПБ и ГУ МЧС России). Сайт позволяет пользователям ознакомиться с историей службы, узнать о требованиях к кандидатам, посмотреть характеристики подразделений и отправить обращение через форму обратной связи.

## Используемый CSS-фреймворк
Bootstrap 5.3.8.

## Способ подключения Bootstrap
Bootstrap подключён **локально** (без использования CDN). Файлы фреймворка размещены в папке `vendor/bootstrap/`.
Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключён после Bootstrap для переопределения стилей и настройки фирменной цветовой схемы МЧС.

## Структура проекта
- `index.html` — Главная страница;
- `catalog.html` — Каталог направлений (с фильтрами);
- `product.html` — Страница подробной информации о ГУ МЧС (таблицы, вкладки, аккордеон);
- `psc.html`, `mac.html`, `mgpss.html` — Уникальные страницы городских структур;
- `order.html` — Форма обратной связи (с валидацией);
- `contacts.html` — Контакты;
- `history.html` — История службы;
- `css/custom.css` — Пользовательские стили;
- `images/` — Изображения и эмблемы;
- `vendor/bootstrap/` — Локальные файлы фреймворка;
- `README.md` — Описание проекта.

## Список реализованных Bootstrap-компонентов
- `navbar` (адаптивная навигация с мобильным меню);
- `card` (карточки направлений);
- `btn` (кнопки различных вариантов);
- `badge` (значки категорий и статусов);
- `alert` (информационные сообщения);
- `modal` (модальное окно с подробной информацией);
- `form-control`, `form-select`, `input-group`, `form-check` (элементы формы);
- `accordion` (раскрывающиеся списки FAQ);
- `tabs` (вкладки на странице товара);
- `carousel` (карусель на главной странице);
- `breadcrumb` (хлебные крошки);
- `table` (таблицы характеристик);
- Сетка: `container`, `row`, `col-*`, `g-*`;
- Utility-классы для отступов, теней, выравнивания.

## Самостоятельные доработки
1. **Локальное подключение Bootstrap** (без CDN) — файлы размещены в `vendor/bootstrap/`.
2. **Расширение структуры проекта** — добавлены 5 дополнительных страниц (`contacts.html`, `history.html`, `psc.html`, `mac.html`, `mgpss.html`).
3. **Дополнительные Bootstrap-компоненты** — реализованы `accordion`, `tabs`, `carousel`.
4. **Улучшение каталога** — добавлены JS-фильтры для сортировки карточек (городские/федеральные).
5. **Визуальная целостность** — настроен `custom.css`, использованы фирменные цвета и градиенты, уникальная стилистика для каждой структуры.
6. **Адаптивность** — проверено отображение на экранах 320px, 768px, 1440px.
7. **Валидация формы** — добавлена проверка обязательных полей на JavaScript.
